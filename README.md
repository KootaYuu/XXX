# 静噪 · 网页白噪音播放器

一个纯前端的白噪音播放器：11 种音景可以自由叠加，每一种的音量独立可调。

所有声音都由浏览器的 Web Audio API **实时合成**，仓库里没有任何 mp3/wav —— 代码总共不到 100 KB，首屏之后完全离线可用，也不会出现循环音频那种听久了就能察觉的"接缝"。

## 快速开始

没有构建步骤，也没有依赖。直接用浏览器打开 `index.html` 即可；如果想通过 HTTP 访问（例如在手机上测试）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

部署时把这三个文件丢到任意静态托管（GitHub Pages / Netlify / Vercel / 对象存储）就行。

## 功能

- **11 种音景**，分三组：
  - 基础噪音 —— 白噪音、粉红噪音、布朗噪音
  - 自然 —— 雨声、远雷、海浪、溪流、风声
  - 室内 —— 篝火、风扇、咖啡馆
- **自由混音**：每张卡片一个独立音量滑块，点卡片名可快速开关。
- **场景预设**：内置专注、助眠、雷雨夜等 6 个组合；调好的混音可以命名保存，存在 localStorage 里。
- **睡眠定时**：15 分钟到 2 小时，结束前 30 秒自动淡出，不会突然断掉。
- **实时频谱**：顶部的可视化直接取自输出总线。
- **快捷键**：<kbd>空格</kbd> 播放/暂停，<kbd>↑</kbd>/<kbd>↓</kbd> 调总音量，<kbd>M</kbd> 静音。
- 自动跟随系统深色/浅色主题，移动端自适应，刷新后恢复上次的混音。

## 声音是怎么合成的

底层是三段 6 秒的循环噪声缓冲区（白 / 粉红 / 布朗），生成时多算 0.25 秒并把这段尾巴交叉淡化回开头，因此循环点听不出接缝；同时做了去直流和归一化。左右声道各自独立生成，听感上有宽度。

各个音景在这三种噪声之上叠滤波器、低频振荡器和随机事件：

| 音景 | 做法 |
| --- | --- |
| 雨声 | 粉红噪音经高通 + 低通，两个不同步的慢速 LFO 制造疏密变化，另有随机的大颗雨滴 |
| 远雷 | 每 12~38 秒一次布朗噪音爆发，低通截止频率在 5 秒内从 ~200Hz 滑落到 70Hz |
| 海浪 | 布朗噪音过低通，音量与截止频率用同一个 0.075Hz 的 LFO 同步推动 —— 浪头拍下来时高频更多 |
| 溪流 | 白噪音过带通，叠加随机的细碎气泡声 |
| 风声 | 布朗噪音过带通，带通中心频率被 0.045Hz 的 LFO 来回扫 |
| 篝火 | 布朗噪音过低通打底，随机触发短促的木柴噼啪 |
| 风扇 | 布朗噪音 + 112Hz 峰值滤波模拟电机嗡鸣，5.6Hz 轻微调幅模拟扇叶 |
| 咖啡馆 | 粉红噪音过带通模拟听不清内容的人声，偶尔一声杯碟轻碰 |

输出总线上挂了一个 `DynamicsCompressor` 做限幅，音景叠多了也不会削顶。所有音量变化都走 `setTargetAtTime` 平滑过渡，避免咔哒声。

## 文件结构

```
index.html   页面结构
styles.css   样式（含深浅色主题与响应式）
app.js       音频引擎 + 音景定义 + 界面逻辑
```

`app.js` 分为四部分：噪声缓冲区生成、音景构建工具（`makeKit`）、音景定义表（`SOUNDS`）、播放引擎与界面。

### 加一种新音景

在 `app.js` 的 `SOUNDS` 数组里追加一项即可，界面会自动生成对应卡片：

```js
{
  id: 'keyboard', name: '机械键盘', icon: '<svg viewBox="0 0 24 24">…</svg>',
  group: '室内', trim: 0.7, desc: '敲击声。',
  build: (k, out) => {
    const lp = k.filter('lowpass', 3000, 0.7);
    lp.connect(out);
    k.every(120, 600, () => {
      k.burst('white', lp, { attack: 0.001, hold: 0.004, release: 0.05, peak: 0.3 });
    });
  },
}
```

`k` 提供 `noise()` / `filter()` / `gain()` / `lfo()` / `every()` / `burst()`，它会自动登记需要回收的节点和定时器，音景关闭时统一释放。`trim` 用来把各音景的响度拉到同一水平，好让滑块的手感一致。

## 浏览器支持

需要 Web Audio API：Chrome、Edge、Firefox、Safari 均可（含 iOS Safari）。浏览器要求首次播放必须由用户手势触发，因此 `AudioContext` 会推迟到第一次点击播放时才创建。
