# 九号机械师 MMAX2 宣传短片（非官方）

32 秒、1920×1080 / 30fps，运动风、快节奏的电动车宣传片。整片按 128 BPM 剪辑，每个转场都落在节拍上。

成片：[`mmax2-promo.mp4`](mmax2-promo.mp4)

> 非官方作品。车辆是自行绘制的风格化示意图，不是真实外观，也没有使用九号的 logo；屏幕界面同样是示意。
> 若用于商业发布，请先取得品牌方授权，并以官方最新参数为准。

## 配乐

`music.py` 用 numpy + scipy 合成（E 小调，128 BPM），无版权问题：心跳与自检提示音 → 电机啸叫上升 → 点火冲击 → 半速段 → 第 3 小节进入 Drop（四踩底鼓、拍手、滚动贝斯、16 分琶音、侧链压缩）→ 每段开头有上升音效和冲击 → 功能和配色切换处有电子音效 → 军鼓滚奏推到收尾冲击 → 和弦余音。

## 重新生成

```bash
./build.sh            # 字体 → 配乐 → 逐帧渲染 → 合成 mmax2-promo.mp4
node render.js --preview 3,10,20   # 导出指定秒数的静帧
```

依赖：Node + Playwright（Chromium）、Python 3 + numpy + scipy、ffmpeg（没有系统 ffmpeg 时会使用 `imageio-ffmpeg`）。
